# ADR-001: OpenStreetMap mediante Overpass como fuente inicial

- **Estado:** aceptado
- **Contexto:** se necesita una fuente pública, consultable y geoespacial para una primera ingesta local.
- **Opciones:** OpenStreetMap/Overpass, directorios comerciales cerrados, dataset municipal estático.
- **Decisión:** usar OpenStreetMap consultado por Overpass con `amenity=cafe`.
- **Consecuencias:** cobertura abierta y reproducible, pero variable; exige atribución ODbL, límites de servicio y documentación de frescura.
